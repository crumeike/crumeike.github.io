## 📁 Image Specifications

**Best dimensions:** 800x500px (16:10 ratio)
**Format:** JPG, PNG, or WebP
**Size:** Under 500KB each

**Tips for good images:**
- Screenshots from your papers
- Model architecture diagrams
- Result visualizations
- Dashboard screenshots
- Professional graphics from Figma/Canva

## 🆘 Troubleshooting

**Images not showing?**
- Check filenames match exactly
- Placeholders will show automatically if images missing

**GitHub links not working?**
- Update the `href` in each project card
- Or remove `<div class="project-overlay">` section

**Details won't expand?**
- Make sure JavaScript is enabled
- Check browser console for errors
